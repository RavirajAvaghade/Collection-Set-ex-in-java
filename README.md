# Java Collection Set Examples 🚀

This repository contains Java programs based on the **Set interface** of the Java Collection Framework.  
These examples help to understand how different types of Sets work in Java.

## 📚 About Set Collection
A **Set** is a collection that:
- Stores unique elements only
- Does not allow duplicate values
- Is part of the Java Collection Framework

## 🔹 Types of Set Used
### 1. HashSet
- Stores unique elements
- Does not maintain insertion order
- Provides fast performance

### 2. LinkedHashSet
- Maintains insertion order
- Stores unique elements

### 3. TreeSet
- Stores elements in sorted order
- Does not allow duplicates
